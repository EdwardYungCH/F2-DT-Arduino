第 1 步 · 今日任務

製作一個行人過路燈

你要把紅、黃、綠三粒 LED 和一個按鈕接到 Arduino UNO。平時是綠燈；有人按掣，燈號就會按香港的次序轉換：黃 → 紅 → 紅＋黃 → 綠。

過路燈怎樣運作？

行人按掣
燈號時間意思
綠燈一直亮平時：車輛可以行，等人按掣
黃燈2 秒有人按掣：車輛準備停車
紅燈5 秒車輛停，行人過路
紅 + 黃2 秒準備開車，之後轉回綠燈

香港和英國一樣，紅燈轉綠燈前會先亮「紅＋黃」，提醒司機準備開車。

你會學到

  1. 用電源軌讓幾個元件共用 GND
  2. 按鈕怎樣接，和為甚麼要加 10kΩ 下拉電阻
  3. 用 digitalRead 讀取按鈕，得到 HIGH 或 LOW
  4. 用 if 和 else 令 Arduino 自己作決定

上一堂的 SOS 燈只會「輸出」：不停做同一件事。今次加入「輸入」，Arduino 要先看看按鈕有沒有被按下，才決定做甚麼。這就是「輸入 → 處理 → 輸出」。

認識電阻

今堂用兩種電阻，樣子很相似，要分清楚。

任務流程

  1. 硬件接線用拖拉方式接好電路，跟着步驟做
  2. 程式填空完成 8 個空格，按「檢查答案」
  3. 選板及上傳像真的一樣選 Board 和 Port，再上傳
  4. 成績報告下載報告檔，交給老師

做得快的同學，完成實物後可以做延伸挑戰：過路「嘀嘀」聲和單車防盜警報。

接錯線或填錯答案都可以再改，但系統會記錄錯誤次數和使用提示次數。進度會自動儲存。

下課前未能完成？按右上角的「未完成？先交報告」，報告只計已完成的部分。之後可以繼續做，完成後再交一份完整報告。
