第 1 步 · 今日任務

製作一盞 SOS 求救燈

你要把一粒 LED 接到 Arduino UNO 的第 13 號腳，再寫程式令它不停閃出 ··· ––– ···（三短、三長、三短）。這就是全世界通用的摩斯密碼求救信號 SOS。

SOS 怎樣閃？

摩斯密碼用長短不同的閃光代表字母。S 是三下短閃，O 是三下長閃。

動作時間程式寫法
短閃（亮）0.2 秒delay(200);
長閃（亮）0.6 秒delay(600);
每下閃光之間（熄）0.2 秒delay(200);
字母之間（熄）0.6 秒delay(600);
一次 SOS 完成後（熄）2 秒delay(2000);

Arduino 的 delay() 用「毫秒」計時：1 秒 = 1000 毫秒。

你會學到

  1. 分辨 LED 的正極（長腳）和負極（短腳），明白為什麼要加電阻
  2. 認識麵包板哪些孔是相通的，用它接駁簡單電路
  3. 讀懂 pinMode、digitalWrite、delay 三個指令
  4. 在 Arduino IDE 選擇開發板和連接埠，然後編譯及上傳程式

SOS 不是任何英文的縮寫。人們選它，是因為「三短三長三短」很容易發送，也很難和其他信號混淆。它在 1908 年起成為國際通用的無線電求救信號。

任務流程

  1. 硬件接線用拖拉方式接好電路，跟着步驟做
  2. 程式填空完成 8 個空格，按「檢查答案」
  3. 選板及上傳像真的一樣選 Board 和 Port，再上傳
  4. 成績報告下載報告檔，交給老師

接錯線或填錯答案都可以再改，但系統會記錄錯誤次數和使用提示次數。進度會自動儲存。

第 2 步

硬件接線

    麵包板：同一個號碼的 a–e 五個孔是相通的（f–j 另一組）。把滑鼠移到孔上，會顯示哪些孔相通。
    LED：長腳是正極（+），短腳是負極（−）。電流只可以由 + 流向 −。
    電阻：限制電流，保護 LED。今次用 220Ω（紅紅啡金）。
