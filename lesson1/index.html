第 1 步 · 今日任務

認識 Arduino，令 L 燈閃起來

Arduino UNO 板上有一粒細小的 L 燈，它在板內已經接到 13 號腳。今堂你要先認識 UNO 板，再寫第一個程式，令 L 燈亮 1 秒、熄 1 秒，不停重複。今堂不用接任何零件。

程式怎樣令 L 燈閃？

電腦把程式經 USB 線上傳到 UNO。之後 UNO 會自己不停執行程式，就算拔走 USB 線、改用電池供電也一樣。

程式意思時間
digitalWrite(13, HIGH);13 號腳輸出 5V：開燈—
delay(1000);等一等1 秒
digitalWrite(13, LOW);13 號腳輸出 0V：關燈—
delay(1000);等一等1 秒

delay() 用「毫秒」計時：1 秒 = 1000 毫秒。四行做完之後，loop() 會由頭再做，所以燈會不停閃。

你會學到

  1. 認識 UNO 板的主要部分：USB 插口、電源插口、RESET 掣、13 號腳、GND、5V、L 燈和主晶片
  2. 知道麵包板上哪些孔是相通的（下一堂接線會用到）
  3. 程式的結構：setup() 只做一次，loop() 不停重複
  4. 三個指令：pinMode、digitalWrite、delay
  5. 第一次選擇開發板（Board）和連接埠（Port），然後上傳程式

Arduino 在 2005 年於意大利誕生，原本是給設計學生用的工具，讓不懂電子的人也可以做出會動、會發光、會發聲的作品。

安全守則

  • 先接線，後通電。改動電路之前，先拔走 USB 線。
  • 5V 不可以直接接到 GND。這樣會短路，UNO 和電腦的 USB 插口都可能損壞。
  • 不要把 UNO 放在金屬或濕的桌面上。板底的焊點碰到金屬也會短路。
  • 拔 USB 線時拿住插頭，不要拉電線。

任務流程

  1. 認識硬件貼標籤、麵包板小測、插 USB 線
  2. 程式填空完成 6 個空格，按「檢查答案」
  3. 選板及上傳第一次上傳，會一步一步帶你做
  4. 成績報告下載報告檔，交給老師

做得快的同學，完成實物後可以做延伸挑戰：心跳燈和修好壞掉的程式。

答錯可以再改，但系統會記錄錯誤次數和使用提示次數。進度會自動儲存。

下課前未能完成？按右上角的「未完成？先交報告」，報告只計已完成的部分。之後可以繼續做，完成後再交一份完整報告。

材料清單

今堂只需要 UNO 和 USB 線。麵包板小測只在電腦上做，不用拿出來。
