RGB 心情燈Arduino UNO 實作

ARDUINO UNO · DTRGB 心情燈

開心是黃色？想休息是藍色？今次為自己的房間設計一盞心情燈。一粒 RGB LED 裏面有紅、綠、藍三粒細燈，Arduino 用 analogWrite 分別調校三種顏色的亮度（0 至 255），就可以混出幾乎任何顏色。

第 1 步 · 今日任務

製作一盞 RGB 心情燈

你要把一粒 RGB LED 接到 Arduino UNO 的 ~9、~10、~11。程式會令燈輪流亮紅色、黃色，再亮你自己調配的心情色。

調色試試看

想要的顏色紅（D9）綠（D10）藍（D11）
紅色25500
黃色 = 紅 + 綠2552550
紫色 = 紅 + 藍2550255
白色 = 三色全開255255255

數字越大越亮：0 = 熄，255 = 最亮。真的 LED 綠色通常特別光，做實物時你可能要把綠色的數字調細一點。

你會學到

  1. RGB LED 怎樣用紅、綠、藍三原色混出其他顏色
  2. 用 analogWrite(腳, 0 至 255) 調校亮度
  3. 只有板上印「~」的腳可以調光：~3、~5、~6、~9、~10、~11
  4. 多個零件時，每種顏色各用一粒電阻

光的三原色是紅、綠、藍（和畫畫顏料不同）。兩種光加在一起會變得更亮：紅 + 綠 = 黃。

認識電阻

今堂只用 220Ω，但套件內還有其他電阻，樣子很相似。

任務流程

  1. 硬件接線用拖拉方式接好電路，跟着步驟做
  2. 程式填空完成 8 個空格（其中 3 格是你自己的心情色），按「檢查答案」
  3. 選板及上傳像真的一樣選 Board 和 Port，再上傳
  4. 成績報告下載報告檔，交給老師

做得快的同學，完成實物後可以做延伸挑戰：用電位器調色，以及彩虹漸變。

接錯線或填錯答案都可以再改，但系統會記錄錯誤次數和使用提示次數。進度會自動儲存。

下課前未能完成？按右上角的「未完成？先交報告」，報告只計已完成的部分。之後可以繼續做，完成後再交一份完整報告。
