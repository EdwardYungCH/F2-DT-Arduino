第 1 步 · 今日任務

製作一個智能停車場閘門

你要把光感應器、紅綠 LED 和一個伺服馬達接到 Arduino UNO。有車遮住光感應器（讀數大過門檻值），就轉綠燈、閘門升到 90°，等 3 秒再落回 0°；沒有車就保持紅燈。

閘門怎樣運作？

A0 讀數 0
情況A0 讀數燈號閘門（伺服馬達）
沒有車細過門檻值紅燈gate.write(0)：0°，關閘
有車遮住光感應器大過門檻值綠燈gate.write(90)：90°，開閘 3 秒

你會學到

  1. 伺服馬達的 3 條線：啡 = GND、紅 = 5V、橙 = 信號
  2. 用 #include <Servo.h> 載入程式庫
  3. 用 attach 設定腳位，用 write 叫伺服馬達轉到指定角度
  4. 重溫：光感應器、門檻值、if / else、LED 及 Serial Monitor

伺服馬達不是一直轉的馬達：你叫它轉到幾多度（0° 至 180°），它就停在那個角度。所以很適合做閘門、門鎖和機械臂。

任務流程

  1. 硬件接線用拖拉方式接好電路，跟着步驟做
  2. 程式填空完成 8 個空格，按「檢查答案」
  3. 選板及上傳像真的一樣選 Board 和 Port，再上傳
  4. 成績報告下載報告檔，交給老師

做得快的同學，完成實物後可以做延伸挑戰：管理員開閘按鈕，以及「慢慢開閘」。

接錯線或填錯答案都可以再改，但系統會記錄錯誤次數和使用提示次數。進度會自動儲存。

下課前未能完成？按右上角的「未完成？先交報告」，報告只計已完成的部分。之後可以繼續做，完成後再交一份完整報告。
