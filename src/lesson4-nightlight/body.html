第 1 步 · 今日任務

製作一盞自動夜燈

你要把一個光感應器和一粒 LED 接到 Arduino UNO。Arduino 不停讀取光感應器：讀數大過門檻值（天黑）就開燈，否則關燈。

夜燈怎樣運作？

A0 讀數 0
環境A0 讀數（大約）夜燈（門檻 700）
電筒照住80關燈
課室燈光450關燈
用手遮住980開燈

記住：這個電路是越暗，讀數越大。真的讀數每塊板、每個課室都不同，做實物時你要自己量度，再決定門檻值。

你會學到

  1. 用 analogRead 讀取類比讀數（0 – 1023）
  2. 光感應器和 10kΩ 電阻組成分壓電路，接到 A0
  3. 用 Serial Monitor 看 Arduino 讀到的數字
  4. 用門檻值和 if / else 決定開燈或關燈

上一堂的按鈕只有兩個狀態：按下（HIGH）或放開（LOW），這叫數碼信號。光暗卻有很多程度，所以要用類比輸入：Arduino 把 0V 至 5V 變成 0 至 1023 的數字。

認識電阻

今堂用兩種電阻，樣子很相似，要分清楚。

任務流程

  1. 硬件接線用拖拉方式接好電路，跟着步驟做
  2. 程式填空完成 8 個空格，按「檢查答案」
  3. 選板及上傳像真的一樣選 Board 和 Port，再上傳，然後打開 Serial Monitor
  4. 成績報告下載報告檔，交給老師

做得快的同學，完成實物後可以做延伸挑戰：用電位器調校靈敏度，以及「越暗越亮」的夜燈。

接錯線或填錯答案都可以再改，但系統會記錄錯誤次數和使用提示次數。進度會自動儲存。

下課前未能完成？按右上角的「未完成？先交報告」，報告只計已完成的部分。之後可以繼續做，完成後再交一份完整報告。
